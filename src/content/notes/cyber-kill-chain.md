title: "Cyber Kill Chain は標的型攻撃を偵察から目的の実行までの7段階に分けたモデルで、ATT&CK はより細かく攻撃者の戦術と手口を整理したもの"
date: 2026-10-20
tags: [security]
---

標的型攻撃で攻撃者がたどる流れを整理したモデルとして、Cyber Kill Chain と MITRE ATT&CK（企業の IT 環境向けが ATT&CK for Enterprise）がある。Cyber Kill Chain は攻撃を偵察から目的の実行までの7段階に分ける。

Cyber Kill Chain はロッキード・マーティン社が提唱したもので、軍事用語の「キルチェーン」（標的の発見から攻撃までの一連の流れ）を攻撃者の行動に当てはめている。段階は次のとおり。

| 段階 | 内容 |
| --- | --- |
| 1. 偵察 | 標的の組織や人物、使っているシステムなどを調べる |
| 2. 武器化 | 標的に合わせたマルウェアや、それを仕込んだファイルを作る |
| 3. 配送 | メールの添付ファイルや Web サイトなどで標的に届ける |
| 4. 攻撃（エクスプロイト） | 脆弱性を突くなどして、マルウェアを実行させる |
| 5. インストール | マルウェアを標的の端末に居座らせる |
| 6. 遠隔操作（C&C） | 外部の C&C サーバーから端末を操る |
| 7. 目的の実行 | 情報の窃取など、もともとの目的を果たす |

このモデルの考え方は、攻撃が段階を順に踏む以上、**どこか1つの段階で鎖を断ち切れば目的の達成を防げる**、というもの。たとえば配送の段階ならメールのフィルタリング、遠隔操作の段階なら C&C サーバーへの通信の遮断、というように、段階ごとに対策を考えられる。

一方の ATT&CK は、実際に観測された攻撃をもとに、攻撃者の「戦術」（何を達成しようとしているか）と「テクニック」（そのための具体的な手口）を一覧表の形でまとめた知識ベース。初期アクセス、権限昇格、横展開、持ち出しといった戦術ごとに多数のテクニックが並んでいて、Cyber Kill Chain よりも侵入後の行動を細かく扱っている。

| | Cyber Kill Chain | ATT&CK |
| --- | --- | --- |
| 提唱 | ロッキード・マーティン | MITRE |
| 粒度 | 7段階の大まかな流れ | 戦術 × テクニックの細かい一覧 |
| 得意な場面 | 攻撃の全体像をつかみ、どこで止めるかを考える | 具体的な手口ごとに検知や対策を検討する |

最後の段階は「情報窃取」と覚えがちだが、目的は情報窃取に限らず、システムの破壊などの場合もある。標的型攻撃では情報窃取が代表例、と押さえておくとよい。
