---
title: "ルーティングは静的と動的に分かれ、動的なプロトコルは AS の内側の IGP と AS の間の EGP に分かれる"
date: 2026-10-12
tags: [network, routing]
---

ルーターのルーティングテーブルを埋める方法には、人が手で書くスタティックルーティングと、ルーター同士が情報を交換して自動で経路を計算するダイナミックルーティングがある。ダイナミックルーティングのプロトコルは、使う範囲によって、1つの組織のネットワーク（AS）の内側で使う IGP（Interior Gateway Protocol）と、AS どうしの間で使う EGP（Exterior Gateway Protocol）に分かれる。

スタティックルーティングは、何が設定されているかが一目で分かる。ただし、機器が増えたり構成が変わったりするたびに手で書き直す必要がある。障害が起きても、自動で別の経路に切り替わることもない。そこで、規模が大きいネットワークや、障害時に迂回させたい場面では、ダイナミックルーティングを使う。

主なプロトコルは次のとおり。

| 区分 | プロトコル | 経路の選び方 | 特徴 |
| --- | --- | --- | --- |
| IGP | RIP | ホップ数が少ない経路（距離ベクトル型） | 単純。帯域は考えない。15 ホップまでなので大規模には向かない |
| IGP | OSPF | リンクの帯域から決まるコストの合計が最小の経路を、ダイクストラ法で求める（リンクステート型） | 広く使われている標準 |
| IGP | IS-IS | OSPF と同じリンクステート型 | 大規模な通信事業者のネットワークでよく使われる |
| IGP | EIGRP | 帯域と遅延から計算した値 | Cisco が作ったプロトコル |
| EGP | BGP | 経由する AS の並びや、運用者が決めたポリシー | インターネットの AS どうしをつなぐ |

同じ宛先への経路を、複数の方法から同時に知ることもある。そのときにどれを採用するかは、経路の情報源ごとの信頼度で決める。この信頼度を、Cisco ではアドミニストレーティブディスタンス（AD）と呼び、値が小さいほど優先される。

| 情報源 | AD（Cisco の既定値） |
| --- | --- |
| 直接接続 | 0 |
| スタティック | 1 |
| eBGP | 20 |
| EIGRP | 90 |
| OSPF | 110 |
| IS-IS | 115 |
| RIP | 120 |

直接つながっているネットワークは、ルーター自身のインターフェースで確かめられるので、最も信頼される。次に優先されるのは、人が意図して書いたスタティックルート。なお AD で比べるのは、宛先のプレフィックスがまったく同じ経路どうしだけ。プレフィックスの長さが違う場合は、AD に関係なく、より長く一致する経路が選ばれる。
