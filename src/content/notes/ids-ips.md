---
title: "IDS は不正な通信を検知するだけで IPS は遮断までする。どちらも見分け方と置き場所で種類が分かれる"
date: 2026-10-18
tags: [security, network]
---

IDS（Intrusion Detection System、侵入検知システム）は不正な通信を見つけて知らせるだけで、IPS（Intrusion Prevention System、侵入防止システム）は見つけた通信をその場で遮断する。どちらも、不正の見分け方（シグネチャ型・アノマリ型）と、置き場所（ホスト型・ネットワーク型）で種類が分かれる。

通信を止めるには、その通信が自分を通っていなければならない。そのため IPS は通信経路に直列につなぐ（インライン）。検査の分だけ遅延が増え、IPS が止まると通信も止まる。IDS は通信を止めないので、スイッチのポートミラーリングで通信のコピーを受け取って見るだけでよく、本来の通信には影響しない。攻撃を確実に止めたいなら IPS、正しい通信を誤って止めるのが怖いなら IDS、と要件で選ぶ。製品によっては、同じ機器を設定でどちらとしても使える。

不正の見分け方には次の2つがある。

| | シグネチャ型 | アノマリ型 |
|---|---|---|
| 判定の基準 | 既知の攻撃のパターンに一致するか | ふだんの状態から外れているか |
| 新しい攻撃 | 見逃す | 見つけられることがある |
| 誤検知 | 少ない | 多くなりやすい |

シグネチャ型はパターンの登録と更新が欠かせない。アノマリ型は、たとえば月末だけアクセスが増えるような正しい通信まで異常とみなすことがある。実際の製品では両方を組み合わせることが多い。

置き場所による違いは次のとおり。IPS にも同じように HIPS と NIPS がある。

| | ホスト型（HIDS） | ネットワーク型（NIDS） |
|---|---|---|
| 置き場所 | 監視したいサーバーの中 | ネットワークの途中 |
| 監視できる範囲 | そのサーバーだけ | 通る通信すべて |
| 暗号化された通信 | 復号したあとの中身まで見られる | 中身は見られない |
| 通信以外 | ログやファイルの改ざんも見られる | 通信しか見られない |

NIDS は L3〜L4 までしか見られない、と思いがちだが、そうではない。暗号化されていない通信なら、アプリケーションのデータまで調べられる。見られないのは、TLS などで暗号化された中身である。
