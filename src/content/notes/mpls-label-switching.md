title: "MPLS は L2 と L3 の間に差し込んだラベルを見て転送する仕組みで、ラベルを2段に重ねると顧客ごとの VPN も作れる"

tags: [network, routing, vpn]
---

MPLS（Multi-Protocol Label Switching）は、L2 のヘッダーと L3 の IP ヘッダーの間に「ラベル」と呼ばれる短い値を差し込み、ルーターがそのラベルを見て転送する仕組み。L2 と L3 の間に入るので、レイヤ 2.5 と呼ばれることもある。

```
| L2 ヘッダー | MPLS ラベル | IP ヘッダー | データ |
```

ふつうの IP ネットワークでは、ルーターはパケットを受け取るたびに宛先 IP アドレスを見て、ルーティングテーブルから最も長く一致する経路を探す。MPLS では、通信事業者のバックボーンのような自分が管理するネットワークの中では、IP パケットをまるごと中身として扱い、ラベルだけで転送先を決める。ラベルは表を1回引くだけで転送先が決まる単純な値なので、処理を軽くできる。

MPLS のネットワークの中で、ラベルは次のように扱われる。

| 場所 | ルーター | ラベルの操作 |
| --- | --- | --- |
| 入口 | LER（ラベルエッジルーター） | IP パケットにラベルを付ける（push） |
| 途中 | LSR（ラベルスイッチルーター） | ラベルを見て転送する。ラベルの値は次のルーター向けに付け替える（swap） |
| 出口 | LER | ラベルを取り去って、ふつうの IP パケットに戻す（pop） |

途中のルーターでラベルの値が付け替わるのは、ラベルの値がルーターとルーターの間でだけ意味を持つため。

ラベルは何段にも重ねられる。これを使うのが、通信事業者が複数の顧客に VPN を提供する MPLS-VPN で、バックボーンの中ではラベルを2段にする。

- **外側のラベル**: バックボーンの中で、出口のルーターまで運ぶための転送用のラベル
- **内側のラベル**: 出口のルーターで、どの顧客の通信かを見分けるためのラベル

途中のルーターは外側のラベルだけを見て転送する。出口のルーターは内側のラベルを見て、その顧客のネットワークへ届ける。顧客ごとに通信が分けられるので、複数の顧客が同じプライベート IP アドレスを使っていても混ざらない。

なお、MPLS は IP のルーティングが遅いことを補うために生まれた面があるが、今はルーターの性能が上がり、IP の転送もハードウェアで十分に速い。現在の MPLS の主な使い道は、速さよりも、上のような VPN や、経路を細かく指定して回線の混雑を避けるトラフィックエンジニアリングになっている。
