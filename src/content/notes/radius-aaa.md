---
title: "RADIUS は AAA を一元管理するプロトコルで、もとはダイヤルアップ用。802.1X とは別物"
date: 2026-10-08
tags: [network, security, radius]
---

RADIUS は、ネットワークの利用者の認証・認可・アカウンティング（AAA）を1台のサーバーでまとめて管理するためのアプリケーション層のプロトコル。正式名称は Remote Authentication Dial In User Service で、名前のとおりもともとはダイヤルアップ接続の利用者を認証するために作られた。無線 LAN 向けに生まれたものではない。

| | 意味 | 例 |
| --- | --- | --- |
| Authentication（認証） | 誰なのかを確かめる | ユーザー名とパスワードを確認する |
| Authorization（認可） | 何をしてよいかを決める | 割り当てる VLAN や IP アドレスを決める |
| Accounting（アカウンティング） | 何をしたかを記録する | 接続した時刻、切断した時刻、通信量 |

Accounting は「課金」と訳されることが多い。ただ、中身は利用の記録なので、お金に関係するとは限らない。訳さずにアカウンティングと呼んだほうが誤解がない。

RADIUS では、認証と認可が1回のやり取りで済む。サーバーが認証に成功すると、返す応答（Access-Accept）に認可の情報も一緒に入れるから。そのため、AAA の3つが最初からきれいに分かれていたわけではない。3つを分けて整理する考え方は後から広まったもので、認証と認可を別々に扱えるようにしたプロトコルには TACACS+ がある。

```text
UDP 1812  認証・認可
UDP 1813  アカウンティング
（古い実装では 1645 / 1646 番を使うこともある）
```

RADIUS と IEEE 802.1X は同じものだと思いがちだが、役割が違う。

- **802.1X**: LAN のポートを、認証に通るまで開けないしくみ。有線 LAN でも無線 LAN でも使う
- **RADIUS**: 802.1X の中で、スイッチやアクセスポイントが認証サーバーに問い合わせるときによく使うプロトコル

802.1X が認証の部品として RADIUS を使うことが多い、という関係。RADIUS は 802.1X 以外にも、VPN やネットワーク機器へのログインの認証などで使われている。
