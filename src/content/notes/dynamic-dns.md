title: "DDNS は変わる IP アドレスを権威 DNS サーバーに報告して追従させる仕組みで、固定 IP がなくても独自ドメインでサーバーを公開できる"
date: 2026-10-25
tags: [network, dns]
---

DDNS（Dynamic DNS）は、IP アドレスが変わるたびにそれを権威 DNS サーバーに報告して、ドメイン名と IP アドレスの対応を自動で書き換える仕組み。プロバイダから毎回違う IP アドレスを割り当てられる自宅のサーバーでも、独自ドメインで公開し続けられる。

DNS は、ドメイン名と IP アドレスの対応がそうそう変わらないことを前提にしている。権威 DNS サーバーに登録した情報は、利用者側のキャッシュ DNS サーバーにしばらく保存されて使い回される。IP アドレスが頻繁に変わると、キャッシュはもちろん、権威 DNS サーバーに書いた情報そのものもすぐ古くなってしまう。そのため、サーバーを公開するには固定 IP アドレスを取るのがわかりやすいが、個人には費用がかさむ。

DDNS では、次のようにして変わる IP アドレスに追従する。

1. 自宅のルーターやサーバーが、自分の IP アドレスが変わったことに気づく
2. 新しい IP アドレスを、DDNS に対応した権威 DNS サーバー（DDNS サーバー）に報告する
3. DDNS サーバーが、そのドメイン名のレコードを新しい IP アドレスに書き換える

あわせて、レコードの TTL（キャッシュしてよい時間）を短くしておく。こうすると、キャッシュ DNS サーバーが古い IP アドレスを使い続ける時間を短くできる。

ただし、DDNS サーバーを自分で立てるには、乗り越えるべき課題がある。

- **DDNS サーバー自体には固定 IP アドレスが要る**: 自宅のサーバーは固定 IP が不要になっても、問い合わせを受ける DNS サーバーの場所は変えられない。
- **踏み台にされない対策が要る**: インターネットに公開する DNS サーバーは、送信元を偽った問い合わせで大きな応答を返させるリフレクション攻撃に悪用されうる。応答の量を制限するなどの対策が必要になる。
- **2台以上の冗長構成が求められる**: 権威 DNS サーバーは、止まるとドメインごと引けなくなるので、プライマリとセカンダリの最低2台を用意するのがふつう。

これらを個人でそろえるのは大変なので、DDNS サーバーの運用を代わりに引き受けるサービスを使うのが一般的。利用者は、IP アドレスが変わったときにサービスへ報告するだけでよい。

なお、ドメイン名と IP アドレスの対応を世界中の DNS サーバーに登録する、と思いがちだが、そうではない。対応を持っているのは、そのドメインを担当する権威 DNS サーバーだけで、他の DNS サーバーは問い合わせのたびにそこへ聞きに行き、結果を一時的にキャッシュしているにすぎない。だからこそ、権威 DNS サーバーの情報を書き換えれば、TTL が切れたところから新しい IP アドレスが行き渡る。
