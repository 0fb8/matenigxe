---
title: "IP-VPN は事業者の閉じた網で拠点を L3 でつなぐサービスで、インターネットにトンネルを作る IPsec VPN とは別物"
date: 2026-10-29
tags: [network, vpn]
---

IP-VPN は、通信事業者の閉じたバックボーンを通して、離れた拠点どうしを L3（IP）でつなぐサービス。名前に VPN とあるが、インターネットの中にトンネルを作るわけではない。

事業者の網を顧客ごとに分けて使う点は、広域イーサネットと同じ。違うのは、つなぐのが L2 か L3 かという点で、IP-VPN では事業者の網がルーターの役割も担う。顧客ごとの通信を分けるには、ふつう MPLS が使われる。L2 か L3 かの違いは、次のような具体的な違いになって表れる。

| | 広域イーサネット | IP-VPN |
| --- | --- | --- |
| つなぐレイヤー | L2 | L3 |
| 通せる通信 | イーサネットのフレームなら何でも | IP パケットだけ |
| 拠点間のルーティング | 利用者が自分で設計・運用する | 事業者の網が担う |
| 自由度 | 高い | 低い |
| 運用の手間 | 大きい | 比較的小さい |

どちらも事業者の網を借りるので、インターネットを使う方式より費用は高い。そのかわり、通信がインターネットに出ないので安全性が高く、事業者によっては帯域の保証や QoS も受けられる。

これとは別に、IPsec VPN という言葉もある。こちらは IPsec でパケットを暗号化してトンネルを作る方式で、ふつうはインターネットを通る。インターネットという誰でも使える網を通るからこそ暗号化が必要になる、という関係なので、単に「IPsec VPN」といえば、たいていはインターネット上に作るインターネット VPN を指していると考えてよい。

| | IP-VPN | IPsec VPN（インターネット VPN） |
| --- | --- | --- |
| 通る網 | 事業者の閉じた網 | インターネット |
| 通信を分ける方法 | 事業者の網で顧客ごとに分ける（MPLS など） | 暗号化して他人に読めなくする |
| 費用 | 高い | 安い |

ただし、IPsec が名前で示しているのは暗号化の方式だけなので、IP-VPN の上で IPsec を使うこともできる。2つは対立する選択肢というより、「どの網を通るか」と「暗号化するか」という別々の話で、よくある組み合わせがそれぞれ名前になっている。
