Amazon SageMaker AI は、機械学習のライフサイクル全体を AWS 上で扱うためのサービスで、MLOps の仕組みを組むのにも使える。機能は、ライフサイクルのどの段階を受け持つかで整理すると覚えやすい。

| 段階 | 機能 | できること |
| --- | --- | --- |
| データ準備 | Data Wrangler | 画面操作でデータの読み込み、クリーニング、変換などの前処理をする |
| | Ground Truth | 画像に「猫」と付けるような、教師あり学習用の正解ラベルを付ける |
| | Feature Store | 作った特徴量を保存し、学習と推論、チームの間で共有する |
| 構築・学習 | Studio | ノートブックなどを備えた、ブラウザで使う統合開発環境 |
| | Canvas | コードを書かずに、画面操作でモデルを作って予測する |
| | JumpStart | 基盤モデル（FM; Foundation Model）などの学習済みモデルや、用途別のテンプレートから始める |
| | Training | 学習ジョブを実行する。必要な間だけインスタンスを立ち上げ、終われば止める |
| デプロイ・自動化 | Endpoints / Batch Transform | 学習したモデルを推論に使えるようにする |
| | Pipelines | データ準備から学習・評価・登録までのワークフローを自動化する |
| | Model Registry | モデルのバージョンを管理し、本番に出してよいかの承認状態を記録する |
| 監視・ガバナンス | Model Monitor | 本番のデータやモデルの品質が学習時からずれていないか（ドリフト）を検知する |
| | Clarify | データやモデルの偏り（バイアス）を調べ、どの特徴量が予測に効いたかを説明する |
| | Model Cards | モデルの用途、学習データ、評価結果などを文書にまとめる |

推論の方式は、要件に合わせて選ぶ。

| 方式 | 向いている場面 |
| --- | --- |
| リアルタイム推論 | 常に低いレイテンシで応答したい |
| サーバーレス推論 | リクエストがまばらで、待機中のコストを抑えたい |
| 非同期推論 | 入力が大きい、または処理に時間がかかる |
| Batch Transform | 大量のデータをまとめて推論し、すぐには結果が要らない |

Ground Truth の名前は、機械学習で「正解データ」を意味する ground truth から来ている。Data Wrangler の wrangle は家畜をまとめて扱うという意味の語で、生のデータを使える形に整える作業をデータラングリング（data wrangling）とも呼ぶ。Training には、ハイパーパラメータの組み合わせを自動で試して良いものを探す機能（自動モデルチューニング）もある。
