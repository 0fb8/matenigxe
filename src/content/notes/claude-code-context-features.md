---
title: "Claude Code には、毎回モデルに渡す情報をうまく扱うための仕組みとして、CLAUDE.md・スキル・MCP・サブエージェント・フックなどがある"
date: 2026-11-08
tags: [ai]
---

モデルは状態を持たないので、ハーネスは毎回、状況をまとめてモデルに渡し直している。Claude Code の機能の多くは、「必要な情報はきちんと渡しつつ、コンテキスト（モデルに渡す情報の枠）を無駄に埋めない」ためにある。よく出てくるものをいくつか挙げる。

| 仕組み | 中身 | コンテキストに入るとき | 向いている用途 |
| --- | --- | --- | --- |
| CLAUDE.md | Markdown のファイル | セッションの開始時から毎回 | プロジェクトの概要、全体に共通するルール |
| スキル | 手順書や資料のファイル | 名前と説明だけ常に入り、本文は使うときに読む | 決まった手順、API の仕様などの参考資料 |
| MCP | 外部のシステムをつなぐ共通規格 | 道具の定義が入る | SaaS や自作システムの操作を道具として渡す |
| サブエージェント | 別のコンテキストで動くエージェント | 結果の要約だけが本線に戻る | 大量のログ調査など、途中経過が多い作業 |
| フック | 決まったタイミングで走るスクリプト | 入らない（ハーネスが実行する） | フォーマッターの実行、危ない操作の阻止 |

- **CLAUDE.md** は AI 向けの README のようなものだ。毎回必ず入るので、細かいことまで書くとそのぶん毎回コンテキストを使う。全体に関わることだけを短く書く。
- **スキル**も中身は文書だが、本文が読まれるのはモデルが必要と判断したときか、利用者が名前を指定して呼んだときだけだ。そのため、手順や資料をたくさん用意しておいても、普段のコンテキストはあまり増えない。
- **MCP** は AI と外部のシステムをつなぐ共通規格で、よく USB にたとえられる。つないだ MCP サーバーの操作は、道具の一覧に加わる。
- **サブエージェント**は、一時的に部下を立てて調べものを任せるようなものだ。大量のログを自分で読むと本線のコンテキストがそれで埋まり、その後の作業に響く。サブエージェントに任せれば、本線には結論だけが戻る。
- **フック**は、モデルではなくハーネスが決まったタイミングで必ず実行する。たとえば「ファイルを編集したらフォーマッターを走らせる」「危ないコマンドは実行前に止める」などだ。モデルが指示を覚えているかどうかに左右されない。

これらをまとめて配れる単位が**プラグイン**だ。スキル・サブエージェント・フック・MCP の設定などを1つにまとめて、チームのメンバーに同じ設定を行き渡らせられる。

ほかにも、どの操作を許可するかという権限の設定がある。設定は、自分のすべてのプロジェクトに効くもの、リポジトリに入れてチームで共有するもの、そのプロジェクトでの自分だけのもの、組織が管理するものなど、いくつかの階層に置けて、重ねて適用される。長くなった会話を要約して縮める `/compact` などのコマンドもあり、知っておくとよいことはまだまだある。
