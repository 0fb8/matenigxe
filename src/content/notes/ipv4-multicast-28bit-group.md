---
title: "IPv4 マルチキャストは先頭4ビットが 1110 で、残り 28 ビットがグループを表す"
date: 2026-10-10
tags: [network, multicast]
---

IPv4 のマルチキャストアドレスは `224.0.0.0/4` で、先頭の4ビットが `1110` に決まっている。残りの 28 ビットは、どのグループ宛てかを表すグループ ID になる。ユニキャストのようにネットワーク部とホスト部に分かれるわけではない。

```text
224.0.0.5 = 1110 | 0000 00000000 00000000 00000101
            ^^^^   ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^
            固定   グループ ID（28 ビット）
```

28 ビットあるので、グループは 2²⁸ 個（およそ 2.7 億個）まで作れる。ただし、その中はさらに用途ごとに分けられている。

| 範囲 | 用途 |
| --- | --- |
| `224.0.0.0/24` | 同じリンクの中だけで使う。ルーターは転送しない（例: `224.0.0.5` OSPF、`224.0.0.18` VRRP） |
| `224.0.1.0/24` | インターネット全体で使う制御用（例: `224.0.1.1` NTP） |
| `232.0.0.0/8` | SSM（送信元を指定して受け取るマルチキャスト）用 |
| `239.0.0.0/8` | 組織の中だけで使う。プライベート IP のマルチキャスト版のようなもの |

28 ビットのグループ ID がそのまま Ethernet の宛先にもなると思いがちだが、MAC アドレスに変えるときに情報が一部失われる。マルチキャスト用の MAC アドレスは `01-00-5E` に続く 24 ビットのうち、先頭の1ビットが 0 に決まっている。そのため、IP アドレスの下位 23 ビットしか入らない。

```text
IP   224.1.1.1 と 225.1.1.1 と 239.129.1.1 …
MAC  どれも 01-00-5E-01-01-01
```

28 ビットのうち上位 5 ビットが MAC アドレスに入らないので、2⁵ = 32 個の IP グループが同じ MAC アドレスを共有する。スイッチや NIC は MAC アドレスだけでは見分けられないので、最後は IP アドレスを見て、自分の参加しているグループか確かめる。
