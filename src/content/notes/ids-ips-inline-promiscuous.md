---
title: "IDS は通信のコピーを見て検知するだけで、IPS は通信経路に直列に入って不正な通信を遮断する"
date: 2026-10-18
tags: [security, network, ids]
---

IDS（Intrusion Detection System、侵入検知システム）は、不正な通信を見つけて知らせるだけの仕組み。IPS（Intrusion Prevention System、侵入防止システム）は、不正な通信を見つけたらその場で遮断する仕組みである。この違いから、置き方も変わる。IPS は通信経路に直列に入れるインライン型、IDS は通信のコピーを受け取るプロミスキャス型で置くのが基本になる。

| | IDS | IPS |
|---|---|---|
| 不正を見つけたら | 管理者に知らせる | 通信を遮断する |
| 置き方 | プロミスキャス型（コピーを見る） | インライン型（経路に直列） |
| 誤検知したとき | 通知が飛ぶだけ | 正しい通信まで止まる |
| 通信への影響 | ほぼない | 遅延が増える。故障すると通信が止まる |

通信を止めるには、その通信が自分を通っていなければならない。そのため IPS は、ルーターやファイアウォールと同じように、通信経路の途中に直列につなぐ。すべての通信が IPS を通るので、検査の分だけ遅延が増え、IPS が止まると通信も止まる。

IDS は通信を止めないので、経路の上にいる必要はない。スイッチのポートミラーリングで、ある経路の通信のコピーを別のポートに流してもらい、そこに IDS をつなぐ。コマンドの `tee` で出力を枝分かれさせるのと同じように、本来の通信はそのまま流れ、IDS はコピーを眺めるだけである。そのため、IDS が遅くても止まっても本来の通信には影響しない。

どちらを使うかは要件による。

- 攻撃を確実に止めたい → IPS
- 正しい通信を誤って止めるのが怖い、通信の速さや安定を優先したい → IDS

製品によっては、同じ機器を設定でどちらとしても使える。たとえば、まず IDS として動かして誤検知の傾向を確かめてから、IPS として遮断を有効にする、といった使い方ができる。
