---
title: "VXLAN は L2 フレームを UDP/IP で包んで L3 の向こうまで運び、24 ビットの VNI で約 1678 万個のネットワークを分けられる"
date: 2026-10-11
tags: [network, vlan, vxlan]
---

VXLAN は、Ethernet フレームをまるごと UDP/IP パケットに包んで運ぶ技術。ルーターをまたいだ離れた場所どうしを、同じ L2 ネットワークのようにつなげる。ネットワークを区別する番号（VNI）は 24 ビットあるので、約 1678 万個まで分けられる。

VLAN は、スイッチの物理的なつなぎ方にしばられずに LAN を分けるための技術。ただ、大きな環境では次の2つが足りなくなる。

- VLAN ID は 12 ビットなので、使えるのは 4094 個まで。たくさんの利用者を収容するデータセンターでは足りない
- VLAN は L2 の中だけの話なので、ルーターを越えると同じ VLAN としてつながらない

VXLAN では、物理的なネットワーク（アンダーレイ）は IP でルーティングされていればよい。その上に、VXLAN で論理的な L2 ネットワーク（オーバーレイ）を作る。オーバーレイの中の端末から見ると、相手は同じ L2 にいるように見える。けれども実際には、L2 のフレームが L3 の上に乗って運ばれている。

```text
[ 外側 Ethernet | 外側 IP | UDP（宛先 4789）| VXLAN ヘッダー（VNI）| 元の Ethernet フレーム ]
                 └──────────── アンダーレイで運ぶための包み ────────────┘
```

包んだりほどいたりするのは VTEP（VXLAN Tunnel End Point）で、スイッチや仮想化ホストがこの役目を持つ。

| | VLAN | VXLAN |
| --- | --- | --- |
| 識別子 | VLAN ID（12 ビット） | VNI（24 ビット） |
| 数 | 4094 個 | 約 1678 万個（2²⁴） |
| 届く範囲 | L2 の中だけ | IP で届くところならどこでも |

包むためのヘッダーが 50 バイトほど増えるので、そのままだと元のフレームが MTU を超えることがある。アンダーレイ側の MTU を大きくする（ジャンボフレームにする）などの対策が必要になる。

なお、VLAN もオーバーレイの一種と呼んでよさそうに思えるが、ふつうオーバーレイと言うのは、VXLAN のように別のネットワークの上をトンネルで運ぶもののことが多い。VLAN は、同じ L2 ネットワークをタグで区切っているだけと考えたほうが区別しやすい。
