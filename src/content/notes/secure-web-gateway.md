---
title: "SWG は境界型の出口対策を担っていたフォワードプロキシをクラウド化したもので、社内を経由せずに Web へのアクセスを検査できる"
date: 2026-10-23
tags: [security, network, zero-trust]
---

SWG（Secure Web Gateway）は、利用者がインターネットの Web サイトにアクセスするときの通信を中継して検査する、クラウド型のプロキシ。境界型セキュリティでいう出口対策、つまり社内の出口に置いたフォワードプロキシが担っていた役割を、クラウドに移したものといえる。

境界型では、社員の Web アクセスはすべて社内の出口のプロキシを通し、そこで検査していた。ところが、リモートワークの社員にも同じ検査をかけるには、いったん VPN で社内に入り、出口のプロキシを通ってからインターネットに出る必要がある。この遠回りで、通信が VPN やプロキシに集中し、ボトルネックになりやすかった。

SWG はクラウドにあるので、次のような違いが生まれる。

| | 社内のフォワードプロキシ | SWG |
| --- | --- | --- |
| 置き場所 | 社内ネットワークの出口 | クラウド |
| リモートの社員の通信 | VPN で社内を経由させる | 社内を経由せず、SWG から直接インターネットへ |
| 利用者が増えたとき | 機器の増強が必要 | クラウド側で処理能力を広げやすい |

社内のシステムを使う必要がない通信まで、わざわざ社内を通さなくてよくなる。また、どこにいる社員にも同じポリシーで検査をかけられる。

SWG で行う制御には、たとえば次のようなものがある。

- **通信先の制限**: 許可した FQDN 以外へのアクセスを遮断する。危険なサイトのカテゴリをまとめて止めることもできる。
- **アップロードの遮断**: 外部のサイトへのファイルのアップロードを止め、情報の持ち出しを防ぐ。
- **マルウェア対策**: ダウンロードするファイルや Web ページを検査する。
- **HTTPS の中身の検査**: 暗号化された通信をいったん復号して、上の検査を行う。

なお、同じクラウド型のプロキシでも、IAP は利用者から**社内のアプリ**への通信を守る。これに対して、SWG は利用者から**インターネット**への通信を守る。守る通信の向きが逆になる。
