---
title: "サイドチャネル攻撃は、処理時間や電磁波など、実装から漏れる本来の出力以外の情報から秘密を推測する攻撃"
date: 2026-10-12
tags: [security]
---

サイドチャネル攻撃は、暗号などのアルゴリズムそのものの弱点ではなく、それを動かしている実装から漏れる情報を手がかりにする攻撃の総称。手がかりになるのは、処理にかかった時間、消費電力、漏れ出る電磁波、音などで、そこから鍵やパスワードを推測する。

名前の「チャネル」は情報の通り道のこと。システムが本来やり取りする入力と出力が、表の通り道（メインチャネル）にあたる。サイドチャネルは、設計者が意図していない横の通り道を指す。暗号そのものが数学的に強くても、横の通り道から秘密が漏れていれば破られてしまう。

主な種類は次のとおり。

| 攻撃 | 手がかり |
| --- | --- |
| タイミング攻撃 | 処理にかかる時間の違い |
| 電力解析攻撃 | 処理中の消費電力の変化 |
| テンペスト攻撃 | 機器から漏れる電磁波（画面の表示内容などを再現する） |
| キャッシュ攻撃 | CPU のキャッシュに載っているかどうかによる、アクセス時間の差 |

タイミング攻撃のわかりやすい例が、パスワードを先頭から1文字ずつ比べ、違った時点で処理を打ち切る実装。

```python
def check(secret, guess):
    for a, b in zip(secret, guess):
        if a != b:
            return False  # 違った時点ですぐ返る
    return len(secret) == len(guess)
```

先頭の何文字が合っているかによって、返るまでの時間がわずかに変わる。攻撃者は、時間が長くなる文字を探して1文字ずつ確定させられる。対策として、合っていてもいなくても同じ時間がかかる比較を使う（Python なら `hmac.compare_digest`）。

タイミング攻撃やキャッシュ攻撃は、機器に近づかなくても、ネットワーク越しや同じマシン上の別のプログラムからできる場合がある。そのため、サイドチャネル攻撃は物理的な接近が必要な攻撃に限らない。CPU の投機実行を悪用した Spectre や Meltdown も、キャッシュの時間差を手がかりにしている。

その他の対策としては、処理時間や消費電力が秘密の値によって変わらないように実装すること、電磁波を遮る（シールドする）ことなどがある。
