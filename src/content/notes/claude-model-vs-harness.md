---
title: "Claude はテキストを返すだけのモデルで、道具の実行と作業の記憶はエージェントハーネスの Claude Code が受け持つ"
date: 2026-11-07
tags: [ai]
---

Claude と Claude Code は別物だ。Claude は入力に対してテキストで応答する大規模言語モデル（LLM）で、Anthropic のサーバーや大手クラウドの上で動いている。Claude Code は利用者の手元で動くソフトで、Claude の代わりにファイル操作などを実行し、作業の経過を覚えておく。こうしたソフトをエージェントハーネスと呼ぶ。

モデルだけでは、テキストを返すことしかできない。環境の中で道具を使って自律的に作業させるには、間を取り持つハーネスが要る。Claude Code は、HTTPS 上の Anthropic の API で Claude と次のようにやり取りする。

1. 使える道具（ファイルの読み書き、コマンドの実行など）の一覧と、ここまでの会話を Claude に送る。
2. Claude は「このファイルにこう書き込みたい」のように、使いたい道具と引数を返す。
3. Claude Code がその操作を実際に行い、結果を会話に足して、また 1 から Claude に送る。

Claude は状態を持たないので、前のやり取りを覚えていない。そのため Claude Code は、毎回それまでの会話と操作の結果を全部まとめて送り直している。つまり Claude Code は、手足の役だけでなく記憶の役も担っている。ただし、毎回同じ部分を一から処理し直すと無駄が大きい。そこで API には、前回と共通する先頭部分の処理結果を使い回すプロンプトキャッシュがある。

Claude Code には機能を足せる。

- **フック**: 道具を使う前後などの決まったタイミングで、登録しておいたスクリプトを実行する。危ない操作を止めるガードレールなどに使う。
- **MCP**: 外部のシステムをつなぐための共通規格。MCP サーバーをつなぐと、そこで定義された操作も道具の一覧に加わり、Claude が使えるようになる。

| つなぐもの | 方式 |
| --- | --- |
| Claude Code と外部のシステム | MCP（会社をまたいだ共通規格） |
| Claude Code と Claude | Anthropic の API（各社が独自に決めた形式） |

モデルとハーネスの組み合わせは、OpenAI の GPT と Codex、Google の Gemini と Gemini CLI のように各社にあり、間の API の形式は会社ごとに違う。そのため、ほかの会社のモデルを Claude Code で動かすには、API の形式を変換する仕組みが要る。逆に言えば、変換さえすれば動かせる。

なお、Anthropic の API の側でもモデルの外の処理が行われている。たとえば Web 検索の道具は、手元のハーネスではなく Anthropic のサーバーで実行される。また Claude は、テキストだけでなく画像も入力として受け取れる。それでも、テキストを返すモデルと、道具を実行して状態を管理するハーネスが分かれているという基本の形は変わらない。
