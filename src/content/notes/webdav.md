---
title: "WebDAV は HTTP にメソッドを足して、Web サーバー上のファイルをローカルのファイルのように作成・編集できるようにする規格"
date: 2026-10-12
tags: [network, http]
---

WebDAV（Web-based Distributed Authoring and Versioning）は、HTTP を拡張して、Web サーバー上のファイルを作ったり、編集したり、移動したりできるようにする規格。HTTP にメソッドを追加することで実現している。利用者は、ブラウザーで操作するのではなく、エクスプローラーなどからネットワークドライブとしてつなぎ、ローカルのファイルと同じ感覚で扱える。

もともとの HTTP には、ファイルを取ってくる `GET`、置く `PUT`、消す `DELETE` くらいしかない。フォルダーの中身の一覧を取ったり、ファイルを移動したりする手段がなかった。WebDAV は、そのためのメソッドを足している。

| メソッド | 役割 |
| --- | --- |
| `PROPFIND` | ファイルの属性（サイズ、更新日時など）や、フォルダーの中身の一覧を取る |
| `PROPPATCH` | 属性を書き換える |
| `MKCOL` | フォルダー（コレクション）を作る |
| `COPY` / `MOVE` | ファイルをコピーする、移動する |
| `LOCK` / `UNLOCK` | ファイルをロックする、ロックを外す |

名前の Distributed Authoring は、離れた場所にいる複数の人が、同じサーバー上のファイルを共同で編集することを指す。同時に書き換えて内容が壊れないように、`LOCK` で編集中のファイルをロックし、ほかの人の書き込みを防ぐ。

HTTP の上で動くので、ふつうの Web サーバーと同じく 80 番や 443 番のポートを使える。ファイアウォールを通しやすく、HTTPS で暗号化もできる。対応しているクライアントの例は次のとおり。

- Windows のエクスプローラー（ネットワークドライブの割り当て）
- macOS の Finder（サーバーへ接続）
- Nextcloud などのファイル共有サービスのクライアント

なお、名前に Versioning（バージョン管理）と入っているが、WebDAV の基本の規格にバージョン管理の機能は入っていない。バージョン管理は、あとから別の規格（DeltaV）として切り出されたが、あまり普及していない。また、カレンダーを共有する CalDAV や、連絡先を共有する CardDAV は、WebDAV を土台にした規格。
